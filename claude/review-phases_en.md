# rOpenSci Software Peer Review: Ten Phases

1. **Pre-Submission (Optional)** - Author discusses package scope with the EIC
2. **Submission** - Author creates issue, bot runs automated checks, EIC reviews and assigns editor
3. **Editor Initial Check (~1-2 weeks)** - Editor reviews package against checklist and pkgcheck report
4. **Finding Reviewers (~2 weeks)** - Editor searches for and recruits 2 reviewers
5. **Review (~2-3 weeks per reviewer)** - Reviewers independently examine package and post reviews
6. **Author Response (~2-3 weeks)** - Author addresses reviewer feedback and makes changes
7. **Iteration (Variable)** - Back-and-forth between reviewers and author until satisfied
8. **Approval** - Reviewers approve, editor runs final approval command, bot posts TODO list
9. **Post-Acceptance - Repository Transfer** - Author enables 2FA and transfers repo to ropensci org
10. **Post-Acceptance - Finalization** - Author completes checklist (links, badges, version bump, etc.)
