# Revisión por Pares de Software de rOpenSci: Diez Fases

1. **Pre-Envío (Opcional)** - Autor discute el alcance del paquete con el EIC
2. **Envío** - Autor crea issue, el bot ejecuta verificaciones automáticas, EIC revisa y asigna editor
3. **Verificación Inicial del Editor (~1-2 semanas)** - Editor revisa el paquete contra lista de verificación e informe de pkgcheck
4. **Búsqueda de Revisores (~2 semanas)** - Editor busca y recluta 2 revisores
5. **Revisión (~2-3 semanas por revisor)** - Revisores examinan el paquete independientemente y publican revisiones
6. **Respuesta del Autor (~2-3 semanas)** - Autor responde a comentarios de revisores y realiza cambios
7. **Iteración (Variable)** - Intercambio entre revisores y autor hasta quedar satisfechos
8. **Aprobación** - Revisores aprueban, editor ejecuta comando de aprobación final, bot publica lista de tareas
9. **Post-Aceptación - Transferencia de Repositorio** - Autor habilita 2FA y transfiere repo a la org ropensci
10. **Post-Aceptación - Finalización** - Autor completa lista de verificación (enlaces, badges, incremento de versión, etc.)
